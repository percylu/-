# 绿茵绝杀 FootballG — 浏览器 3D 足球射门游戏

一个完全运行在浏览器里的 3D 足球射门游戏：夜场球场、泛光灯、会扑救的门将、会鼓掌跳跃的看台、带马格努斯效应的足球物理、转播式镜头与慢动作回放。包含「点球大战」和「任意球挑战」两种模式，界面全部为简体中文。

本目录是自包含的前端工程（Three.js + Vite），与仓库里的 PHP 项目互不依赖，也没有改动任何 PHP 代码。

## 运行

需要 Node.js 20 及以上。

```bash
cd footballg
npm install
npm run dev        # 开发服务器：http://localhost:5173/
```

生产构建与本地预览：

```bash
npm run build      # 输出到 footballg/dist（纯静态文件，可放到任意静态服务器）
npm run preview    # http://localhost:4173/
```

## 玩法

| 模式 | 说明 |
| --- | --- |
| 点球大战 | 十二码前 5 轮。点球点、助跑路线与门将站位每轮略有不同；门将多数时候看球晚反应，偶尔也会提前赌一侧。 |
| 任意球挑战 | 5 个随机位置（19–27 米），3–5 人人墙会起跳，门将站在人墙另一侧。皮球带上旋，力量适中时能越过人墙后下坠。 |

进球得 100 分，角度越刁、球速越快、任意球都有额外加分。5 轮后给出评级，最高分保存在浏览器本地。

### 操作

| 设备 | 瞄准 | 蓄力 / 射门 | 弧线 |
| --- | --- | --- | --- |
| 鼠标 | 移动鼠标，准星落在球门平面上 | 按住左键蓄力，松开射门 | 蓄力时左右拖动 |
| 触屏 | 在屏幕上拖动（相对移动准星） | 按住「射门」按钮蓄力，松开射门 | 按住按钮时左右滑动 |
| 键盘 | — | 按住空格蓄力，松开射门 | A / D 或 ← / → |

- 按住越久力量越大（不再来回摆动）；超过约 88% 力量条变红：球速更快，但落点误差变大，也容易打高。
- 射门时球在脚触球的瞬间才离开地面，门将也在那时才开始读取来球。
- 回放时点击屏幕或按任意键可以跳过。

### 难度

「简单 / 普通 / 困难」改变门将的反应时间、移动速度、猜对方向的概率和预判误差；每一轮门将都会比上一轮更准一点。`tools/scripts/balance.mjs` 用蒙特卡洛批量射门来校准这些数值（普通难度下点球随机落点约 55% 进球，打到死角约 80%）。

## 画质设置

主菜单里可以切换画质（切换后会重新载入球场）。首次进入时按显卡自动选择：独立显卡 / Apple 芯片默认「高」，其他默认「中」，检测到软件渲染（没有 GPU）时默认「低」。运行中如果帧率低于约 40 FPS，会自动逐步降低内部渲染分辨率（最低 50%，软件渲染时最低 30%），帧率恢复后再升回去。

| 档位 | 阴影 | 后处理 | 3D 草叶 | 观众密度 | 像素比上限 |
| --- | --- | --- | --- | --- | --- |
| 低 | 1 盏灯，1024 | 无（仅 ACES 色调映射） | 无 | 40% | 0.8 |
| 中 | 2 盏灯，1024 | 泛光 + SMAA + 调色 | 无 | 75% | 1.0 |
| 高 | 4 盏灯，2048 | 环境光遮蔽 + 景深 + 球体拖影 + 泛光 + SMAA + 调色 | 7 万 | 100% | 1.5 |
| 极致 | 4 盏灯，4096 | 同上，外加 4×MSAA | 15 万 | 100% | 2.0 |

URL 参数（调试用）：`?q=low|medium|high|ultra` 指定画质，`?debug` 显示帧率和绘制统计，`?start=penalty|freekick` 直接开始，`?seed=数字` 固定随机种子，`?mute` 静音，`?capture` 关闭实时循环、改由脚本逐帧推进。

## 画面与技术实现

- **渲染管线**：Three.js（WebGL2）+ `postprocessing`。HDR 半浮点帧缓冲 → N8AO 环境光遮蔽 → 景深 → 足球运动拖影 → 泛光、暗角、ACES 色调映射、对比度与饱和度 → SMAA。
- **光照**：四组泛光灯（方向光，强度不对称，产生足球场典型的多重影子），PCF 软阴影跟随球与球门区域；场景自身烘焙成 PMREM 环境贴图，提供基于图像的反射和补光；指数雾 + 发光灯阵触发泛光。
- **草皮**：一个着色器里完成割草条纹（随视角变化明暗）、解析距离场画出的全部标线（任何距离都清晰不闪烁）、磨损和细节法线；「高」以上在镜头附近铺实例化 3D 草叶。
- **球场**：两层环形看台、屋顶和桁架、LED 广告牌与层间灯带、角旗、实例化的观众（分扇区做视锥剔除，进球后跳跃挥手）、看台闪光灯。
- **足球**：32 片皮面的贴图与凹凸贴图在启动时烘焙，清漆物理材质。物理为重力 + 空气阻力 + 马格努斯力（旋转 × 速度），1/480 秒子步；与地面、门柱、横梁、广告牌、人体胶囊体做带恢复系数和摩擦的冲量碰撞，旋转与反弹互相耦合。
- **球网**：三块 Verlet 布料（顶网、后网、侧网），边缘固定在门框上，皮球把网顶出去的同时被网减速兜住。
- **球员**：程序化生成的 17 骨骼蒙皮人形（手绘脸型贴图、发型轮廓、布料褶皱与号码）。射手用步态 IK 助跑、支撑脚落点与脚背触球出球；门将蹬地—腾空—落地—起身，手臂双骨 IK 追球，扑救后可能被脱手反弹。
- **镜头**：开场摇臂、瞄准机位、跟球机位、庆祝和门将特写，以及两段慢动作回放（触球特写 + 网后 / 边线长焦 / 门柱机位）。回放是对球、球员骨骼和球网的逐帧快照做插值重放。
- **声音**：全部用 WebAudio 实时合成（哨声、踢球、触网、门柱、手套、观众底噪与欢呼），没有音频文件。

## 自测与录制工具

这些脚本用系统里的 Chrome 无头运行游戏（`CHROME` 环境变量可指定路径，默认 `/usr/local/bin/google-chrome`），需要先启动开发服务器。

```bash
node tools/shot.mjs --url "http://localhost:5173/?capture&q=high" --out shot.png   # 截一张图
node tools/live.mjs                                                              # 用真实鼠标事件实时玩 3 轮
node tools/play.mjs --script tools/scripts/balance.mjs                            # 批量射门，统计进球 / 扑救率
node tools/play.mjs --script tools/scripts/stills.mjs --url "http://localhost:5173/?capture&q=high&mute" --out /tmp/stills
node tools/play.mjs --script tools/scripts/demo.mjs --seed 5 --frames .capture/frames --stills .capture/stills \
     --url "http://localhost:5173/?capture&q=high&mute"                          # 逐帧录制演示
ffmpeg -framerate 30 -i .capture/frames/f%05d.jpg -c:v libx264 -pix_fmt yuv420p -crf 17 gameplay.mp4
```

`?capture` 模式下游戏不走实时循环，由脚本以固定的 1/30 秒步长推进并逐帧截图，所以即使机器没有 GPU 也能得到完整画质、帧率稳定的视频。

## 资源与许可

- **没有使用任何外部美术、模型、贴图、字体或音频文件。** 草皮、足球、球网、观众、广告牌、球衣号码等贴图都由 `src/world/textures.js` 在启动时用 Canvas 绘制；球员、球场、球门的几何体由代码生成；音效由 WebAudio 合成；文字使用系统字体。这些内容随本目录的代码一起以 MIT 许可提供。
- 球队、球员名、广告牌文字均为虚构，没有使用 EA / FIFA 的商标、界面素材，也没有真实俱乐部、赛事或球员的名称与肖像。
- 运行时依赖：

## 与主机版足球游戏的差距

这是一个由代码生成全部内容的网页游戏，画面是「风格化的转播感」，和 FIFA 这类 3A 作品还有明显距离：

- **球员**：程序化的低模人形，没有扫描级的脸、头发和皮肤材质，没有次表面散射，球衣没有布料模拟；动画是手写关键帧加 IK，不是动作捕捉，没有手指和表情。
- **观众**：是朝向镜头的贴图卡片，近看能看出是平面；只有整体跳跃挥手，没有单独的 3D 模型和动作。
- **草皮**：近处有 3D 草叶，远处靠着色器，没有球和脚踩过后的形变与溅起的草屑。
- **光照**：实时方向光阴影 + 一次性烘焙的环境贴图，没有全局光照、体积光束和屏幕空间反射；环境光遮蔽是屏幕空间近似。
- **物理与动画的结合**：球与身体是胶囊体碰撞；射手触球是按时间点对齐，没有基于物理的脚部接触；门将落地没有布娃娃效果。
- **玩法范围**：只有点球和任意球两种定位球，没有完整比赛、没有防守球员跑动、没有解说和真实球队授权。
- **性能**：没有 GPU（纯软件渲染）的机器上只能以低画质、低分辨率运行，帧率约 10 FPS。各档位在真实显卡上的帧率没有在本仓库的环境里实测过。
